DIGITAL NOTICE BOARD - STANDALONE VERSION

This version does NOT use XAMPP, Apache, MySQL or phpMyAdmin.

How to run:
1. Extract the ZIP.
2. Open the extracted folder.
3. Double-click index.html.
4. Click Admin Login.

Admin login:
Email: admin@gmail.com
Password: admin123

Features:
- Public notice board
- Admin login
- Admin dashboard
- Add notice
- Manage/delete notices
- Categories
- Users
- Logout

Data is stored in the browser's localStorage.

Important:
This is a standalone/demo application. The login is not suitable for production security because
credentials are stored in JavaScript. For a real deployed system, a backend database and secure
password hashing should be used.
